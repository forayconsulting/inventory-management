# Claude Code Workshop — Notes

Four Claude Code features. One app you'll ship today.

1. **CLAUDE.md** — Persistent memory
2. **Plan Mode** — Design before build
3. **MCP** — External tools
4. **PR Review** — Automated reviewer

**The Goal:** A chance to experience Claude Code — and build something that runs. Step-by-step walkthrough you could turn around and run with your clients.

**How this works:**
- **Build Mode** — Claude does the building. You describe what you want. Claude writes the code, creates files, runs commands. This is what your clients will expect their developers to be able to do. Today you experience it firsthand.
- **Your Pace** — Work at your own pace. Follow the steps in order. Click "I'm done" to earn points. Pair up at your table if you want to.
- **Your Copilot** — If you have a question, ask Claude. "Why did this fail?" "What does this file do?" "How do I push to GitHub?" Claude is your pair programmer the whole time. Use it.

**A few things you'll want to know:**
1. You'll approve a lot of permissions. Claude asks before it runs commands or edits files. Say yes or enable auto mode.
2. Sometimes Claude works for a while. It's thinking, writing, testing. Give it a minute. Don't panic, don't cancel it.
3. Don't sit there stuck. If something isn't working, raise your hand. Twenty minutes of silent frustration helps nobody.
4. You don't need to know every feature. Describe what you want in plain English and watch what happens. The full feature set can wait.

**Two paths. Pick yours.**
- **You're set up** — Claude Code installed, terminal works, API key ready. Go straight in.
- **Something's broken** — Table coaches are here to help. Even troubleshooting setup can be part of the experience. Ask Claude to help you.

If you haven't done the setup yet, table coaches can walk you through that in a few minutes.

**Exercise Features — Try not to miss these:**
1. **Connect Claude Code to GitHub** — Automated PR reviews. Tag @claude in an issue or comment and it picks up the work.
2. **Wire in the Playwright MCP** — Gives Claude eyes on your UI. Drives a real browser, clicks through flows, catches what you'd miss.
3. **Advanced workflows** — Step 12 explores skills, subagents, hooks, plugins. The scaffolding for real, reliable automation.
