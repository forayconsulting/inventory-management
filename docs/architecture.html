Tech Stack

Frontend

  • Vue 3 with Composition API
  • Vite dev server (port 3000)
  • Axios for HTTP requests
  • Custom SVG charts (no chart library)
  • Scoped CSS with CSS variables
  • i18n support (English / Japanese)

Backend

  • Python FastAPI framework
  • Uvicorn ASGI server (port 8001)
  • Pydantic v2 data validation
  • CORS middleware (open in dev)
  • In-memory filtering functions
  • Auto-generated OpenAPI docs

Data

  • JSON flat-files (no database)
  • Loaded once at server startup
  • 7 data files in server/data/
  • inventory, orders, demand_forecasts
  • backlog_items, spending, transactions
  • purchase_orders

Shared Patterns

  • Composables: useFilters, useAuth, useI18n
  • Centralized API client (api.js)
  • Singleton filter state across views
  • Currency formatting utilities
  • Loading / error state handling
  • CSS Grid + Flexbox layouts

Composables

useFilters
Singleton reactive filter state shared across all views. Provides selectedPeriod, selectedLocation, selectedCategory, selectedStatus refs and getCurrentFilters() helper.
useAuth
Authentication composable managing user session state, login/logout flows, and profile data.
useI18n
Internationalization composable supporting English and Japanese locales via locale files in src/locales/.

API Endpoints

Method Endpoint Description Filters / Params
Dashboard
GET /api/dashboard/summary Aggregated KPI summary (inventory value, low stock, pending orders, backlog count, total order value) warehouse category status month
Inventory
GET /api/inventory List all inventory items warehouse category
GET /api/inventory/{item_id} Get single inventory item by ID path: item_id
Orders
GET /api/orders List all orders with full filter support warehouse category status month
GET /api/orders/{order_id} Get single order by ID path: order_id
Demand & Backlog
GET /api/demand Demand forecasts (current vs. forecasted, trend) none
GET /api/backlog Backlog items with purchase order status flag none
Spending
GET /api/spending/summary Spending KPI overview none
GET /api/spending/monthly Month-by-month spending breakdown none
GET /api/spending/categories Spending grouped by category none
GET /api/spending/transactions Recent transaction list none
Reports
GET /api/reports/quarterly Quarterly performance (orders, revenue, fulfillment rate) none
GET /api/reports/monthly-trends Month-over-month order and revenue trends none
Tasks & Purchase Orders
GET /api/tasks List all tasks none
POST /api/tasks Create a new task body: task data
PATCH /api/tasks/{taskId} Toggle task completion path: taskId
DELETE /api/tasks/{taskId} Delete a task path: taskId
POST /api/purchase-orders Create purchase order for backlog item body: PO data
GET /api/purchase-orders/{backlogItemId} Get purchase order by backlog item path: backlogItemId

Project Structure

client/

  • src/main.js — App entry point
  • src/App.vue — Root component + global styles
  • src/api.js — Centralized API client
  • src/views/*.vue — 7 page-level views
  • src/components/*.vue — Modals, FilterBar, etc.
  • src/composables/ — useFilters, useAuth, useI18n
  • src/locales/ — en.js, ja.js
  • src/utils/currency.js — Formatting helpers

server/

  • main.py — FastAPI app + all endpoints
  • mock_data.py — JSON loader module
  • data/inventory.json — Inventory items
  • data/orders.json — Order records
  • data/demand_forecasts.json — Forecasts
  • data/backlog_items.json — Backlog queue
  • data/spending.json — Spending summary
  • data/transactions.json — Recent transactions
  • data/purchase_orders.json — PO records
